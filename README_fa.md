# عطرسان: نسخه‌ی نمایشی در Streamlit

این پوشه نسخه‌ی کامل فارسی و راست‌به‌چپ سایت عطرسان را در Streamlit اجرا می‌کند تا بتوانید آن را به مدیرتان نشان دهید.

## اجرا (ویندوز، مک یا لینوکس)

۱. **پایتون** نسخه‌ی ۳.۹ یا جدیدتر را نصب کنید (python.org).

۲. ترمینال (یا Command Prompt) را باز کنید و به این پوشه بروید:

```
cd atrsan_streamlit
```

۳. Streamlit را نصب کنید:

```
pip install -r requirements.txt
```

۴. برنامه را اجرا کنید:

```
streamlit run app.py
```

۵. مرورگر به‌صورت خودکار باز می‌شود (معمولاً روی `http://localhost:8501`).

## محتوای پوشه

| فایل | کاربرد |
|---|---|
| `app.py` | برنامه‌ی Streamlit با راهنمای نمایش در نوار کناری |
| `atrsan_fa.html` | کل سایت در یک فایل، با فونت‌های فارسی داخلی |
| `requirements.txt` | پیش‌نیازها |
| `.streamlit/config.toml` | رنگ‌ها و تنظیمات ظاهری |

## نکته‌ها

- فایل `atrsan_fa.html` را بدون Streamlit هم می‌توانید با دوبار کلیک در مرورگر باز کنید.
- برای نمایش آنلاین (مثلاً برای مدیری که در جای دیگری است):
  1. پوشه را در یک مخزن GitHub بگذارید.
  2. آن را در share.streamlit.io به‌صورت رایگان منتشر کنید.
- همه‌ی محصولات، سفارش‌ها و مشتریان نمونه هستند. پرداخت (شاپرک یا زرین‌پال) فقط شبیه‌سازی شده است.
- قیمت‌ها به تومان و تاریخ‌ها شمسی هستند.
