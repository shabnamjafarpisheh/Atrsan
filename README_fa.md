# عطرسان: نسخه‌ی نمایشی در Streamlit

این پوشه نسخه‌ی کامل فارسی و راست‌به‌چپ سایت عطرسان را در Streamlit اجرا می‌کند تا بتوانید آن را به مدیرتان نشان دهید.

## سریع‌ترین راه اجرا

- **ویندوز:** روی فایل `run_windows.bat` دوبار کلیک کنید.
- **مک یا لینوکس:** در ترمینال بنویسید `sh run_mac_linux.sh`

(فقط باید پایتون نصب باشد؛ بقیه خودکار انجام می‌شود.)

## اجرا (ویندوز، مک یا لینوکس)

۱. **پایتون** نسخه‌ی ۳.۹ یا جدیدتر را نصب کنید (python.org).

۲. ترمینال (یا Command Prompt) را باز کنید و به این پوشه بروید:

```
cd atrsan_streamlit
```

۳. Streamlit را نصب کنید:

```
pip install -r requirements.txt
```

۴. برنامه را اجرا کنید:

```
streamlit run app.py
```

۵. مرورگر به‌صورت خودکار باز می‌شود:

- **فروشگاه:** `http://localhost:8501`
- **پنل مدیریت (جدا از فروشگاه):** `http://localhost:8501/admin`

برای رفتن به پنل مدیریت، پایین صفحه‌ی فروشگاه روی دکمه‌ی «ورود مدیران (پنل مدیریت)» بزنید یا مستقیم آدرس `/admin` را باز کنید. ورود با نام کاربری، رمز عبور و کد دومرحله‌ای است. در نسخه‌ی نمایشی اطلاعات ورود از پیش وارد شده است.

## محتوای پوشه

| فایل | کاربرد |
|---|---|
| `app.py` | صفحه‌ی فروشگاه در Streamlit |
| `pages/admin.py` | صفحه‌ی پنل مدیریت در آدرس `/admin` |
| `common.py` | تنظیمات مشترک نمایش تمام‌صفحه |
| `atrsan_fa.html` | کل فروشگاه در یک فایل، با فونت‌های فارسی داخلی |
| `atrsan_admin_fa.html` | پنل مدیریت در یک فایل جداگانه |
| `run_windows.bat` / `run_mac_linux.sh` | اجرای سریع با دوبار کلیک |
| `requirements.txt` | پیش‌نیازها |
| `.streamlit/config.toml` | رنگ‌ها و تنظیمات ظاهری |

## نکته‌ها

- فایل `atrsan_fa.html` را بدون Streamlit هم می‌توانید با دوبار کلیک در مرورگر باز کنید.
- برای نمایش آنلاین (مثلاً برای مدیری که در جای دیگری است):
  1. پوشه را در یک مخزن GitHub بگذارید.
  2. آن را در share.streamlit.io به‌صورت رایگان منتشر کنید.
- همه‌ی محصولات، سفارش‌ها و مشتریان نمونه هستند. پرداخت (شاپرک یا زرین‌پال) فقط شبیه‌سازی شده است.
- قیمت‌ها به تومان و تاریخ‌ها شمسی هستند.

## مسیر پیشنهادی نمایش برای مدیر

1. **خانه:** طراحی هنری، بطری‌ها و دود متحرک.
2. **یافتن عطر:** بنویسید «عطر شیرین با وانیل و عود» یا «گل رز بدون عود».
3. **آزمون:** به ۸ سؤال جواب دهید و تیپ عطری خود را ببینید.
4. **صفحه‌ی محصول و مقایسه:** هرم نت‌ها و مقایسه‌ی چند عطر.
5. **آتلیه:** ساخت عطر اختصاصی، مرحله‌به‌مرحله.
6. **سبد و پرداخت:** کد تخفیف `ATRSAN10`.
7. **پنل مدیریت:** آدرس `/admin` را باز کنید؛ داشبورد فروش، سفارش‌ها، انبار، مشتریان و نقش‌ها.
8. **راهنمای عطر:** طرز استفاده از عطر و تاریخچه‌ی عطرسازی (از منوی بالا یا صفحه‌ی اصلی).
9. **درباره‌ی ما:** داستان عطرسان، مزیت‌ها و اطلاعات تماس.
10. **موبایل:** سایت را با گوشی باز کنید (منوی ☰، دسته‌ها، فصل‌ها و پنل مدیریت روی موبایل هم کار می‌کنند).
